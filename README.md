📦自定义资源包（res_map.json）功能说明｜Custom Resource Pack (res_map.json)｜カスタムリソースパック（res_map.json）について
 
中文：
本引擎内置自定义资源包扩展功能：用户可以准备一个ZIP压缩包，包内放置名为 res_map.json 的配置文件。在 res_map.json 中可以定义素材ID、内部路径、素材类型（图像 / 音频 / 字体等）与加载参数；引擎将按照该配置加载包内素材，用来扩展自定义剧情资源。⚠️重要：引擎不会自动从互联网下载任何资源包，资源包只能由用户手动选择本机ZIP文件加载。第三方制作资源包的版权、合规责任归该包制作者与使用者本人；本功能仅为扩展接口，不是游戏解包工具，也不鼓励导入从游戏内提取出来的官方资源。
 
English:
This engine includes a custom resource‑pack extension feature: You may prepare a ZIP archive containing a configuration file named res_map.json. Inside res_map.json, you can define asset IDs, internal paths, asset types (image / audio / font, etc.) and loading parameters. The engine will load bundled assets following this configuration to expand custom story resources.⚠️Important: The engine never downloads resource packs automatically from the Internet. You must manually select a local ZIP file to load one. Copyright and compliance for third‑party packs rest with their creator and end user. This feature is only an extension interface; it is NOT a game‑extraction tool, and importing dumped official game assets is not encouraged.
 
日本語：
本エンジンにはカスタムリソースパック拡張機能が実装されています。利用者はZIPアーカイブの中にres_map.jsonという設定ファイルを配置することができます。res_map.json内で素材ID・内部パス・素材種別（画像・音声・フォントなど）および読み込みパラメータを定義すると、エンジンはその設定に従って同梱素材を読み込み、独自のシナリオリソースを追加できます。⚠️重要：本エンジンはインターネットから自動的にリソースパックをダウンロードすることはありません。読み込むには利用者自身が手元のZIPファイルを選択する必要があります。第三者が作成したパックの著作権・適合性の責任はパック作成者と利用者にあります。本機能は拡張用インターフェースに過ぎず、ゲームデータ抽出ツールではなく、ゲームから抜き出した公式アセットの利用も推奨しません。
